# 📚 eBooks y material gratuito — Semana 03

Lecturas libres para profundizar en lo que la teoría resume. Ninguna es obligatoria.

| Recurso | Por qué vale la pena | Comprobado |
|---|---|:--:|
| [Documentación de uv](https://docs.astral.sh/uv/) — Astral | Funciona como un libro completo sobre proyectos, lockfiles, versiones de Python y caché. Lee "Projects" y "Concepts" de corrido; el resto es referencia | 2026-11-02 |
| [Working on projects](https://docs.astral.sh/uv/guides/projects/) — Astral | El ciclo `uv init` → `uv add` → `uv lock` → `uv sync` → `uv run` en una página: lo que haces en la práctica 01 | 2026-11-02 |
| [pytest documentation (PDF)](https://docs.pytest.org/_/downloads/en/latest/pdf/) — pytest | Toda la documentación de pytest descargable. Los capítulos de *markers* y *fixtures* explican los tests de `api/tests/` | 2026-11-02 |
| [Writing your pyproject.toml](https://packaging.python.org/en/latest/guides/writing-pyproject-toml/) — Python Packaging User Guide | Qué es cada tabla de `pyproject.toml` (`[project]`, `[dependency-groups]`, `[build-system]`, `[tool.*]`) según el estándar, no según una herramienta | 2026-11-02 |
