# Bootcamp GitHub Actions — Zero to Advanced

20 semanas · 10 h/semana · 200 horas. Una organización gratuita, un repo
público `<tu-org>/tablero` y un solo pipeline que crece capa a capa.

La columna **Estado** dice la verdad sobre el repositorio: ✅ la semana está
publicada al estándar de [`CLAUDE.md`](../CLAUDE.md), ⬜ todavía no se escribió.
Las semanas sin publicar no llevan enlace. El contenido se escribe en orden.
