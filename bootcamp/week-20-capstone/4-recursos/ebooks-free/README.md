# 📚 eBooks y material gratuito — Semana 20

Guías largas y gratuitas para el capstone y para preparar el GH-200. La primera es la única
obligatoria: la guía de estudio oficial es el temario del examen, y la
[teoría 06](../../1-teoria/06-el-examen-gh-200.md) te enseña a marcarla habilidad por habilidad.
Las demás sirven para escribir la defensa con criterio y para seguir más allá de `tablero`.

| Recurso | Por qué vale la pena | Comprobado |
|---|---|:--:|

| [GitHub Actions certification](https://learn.microsoft.com/en-us/credentials/certifications/github-actions/) — Microsoft Learn | La página oficial del examen: el sitio donde se consultan los datos que este bootcamp no afirma, el día que reserves | 2026-11-14 |
| [Automate your workflow with GitHub Actions](https://learn.microsoft.com/en-us/training/paths/automate-workflow-github-actions/) — Microsoft Learn | La ruta de formación oficial: repasa con otras palabras y otros ejemplos lo que hiciste en `tablero` | 2026-11-14 |
