# 🎬 Videografía — Semana 20

Vídeos para repasar antes del simulacro y para preparar la defensa, todos con título y canal
comprobados. Varios ya salieron en semanas anteriores: esta semana los ves con otra pregunta en la
cabeza, "¿sabría defender esto?". No hay vídeos que se puedan recomendar sobre anclas de YAML en
Actions ni sobre la guía de enero de 2026: para eso, la teoría 05 y la webgrafía. Los cursos
largos usan versiones y etiquetas anteriores a las de `tablero` (`ubuntu-latest`, tags en lugar de
SHA): quédate con el mecanismo y escríbelo con las reglas del bootcamp.
