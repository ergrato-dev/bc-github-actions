# 📚 eBooks y material gratuito — Semana 07

Lecturas libres para profundizar en lo que la teoría resume. Ninguna es obligatoria.

| Recurso | Por qué vale la pena | Comprobado |
|---|---|:--:|
| [Pro Git, Revision Selection](https://git-scm.com/book/en/v2/Git-Tools-Revision-Selection) — Scott Chacon y Ben Straub | El apartado "Commit Ranges" explica los rangos de dos y tres puntos con dibujos. Es la base del diff que GitHub usa para `paths` en `push` y en `pull_request` | 2026-11-02 |
| [Pro Git](https://git-scm.com/book/en/v2) — Scott Chacon y Ben Straub | El libro completo, libre. Para esta semana bastan las ramas y la selección de revisiones si `before..after` o `base...head` te suenan raros | 2026-11-02 |
| [The Linux Command Line](https://linuxcommand.org/tlcl.php) — William Shotts | Libro libre con un capítulo sobre procesos y señales. Ayuda a entender qué hace tu script cuando recibe `SIGINT` y `SIGTERM` al cancelar un run | 2026-11-02 |
| [Keeping your GitHub Actions and workflows secure: Untrusted input](https://securitylab.github.com/resources/github-actions-untrusted-input/) — GitHub Security Lab | El artículo de referencia sobre inyección por expresiones, con ejemplos reales. Es la versión larga de la sección 4 de la teoría 08 | 2026-11-02 |
| [Keeping your GitHub Actions and workflows secure: Preventing pwn requests](https://securitylab.github.com/resources/github-actions-preventing-pwn-requests/) — GitHub Security Lab | Por qué `workflow_run` corre con privilegios aunque el run vigilado venga de un fork. Adelanta el patrón seguro de la Semana 12 | 2026-11-02 |
