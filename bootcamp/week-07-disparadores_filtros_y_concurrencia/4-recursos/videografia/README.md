# 🎬 Videografía — Semana 07

Vídeos en inglés. Casi todos fijan las actions por tag, usan `ubuntu-latest` o ponen
`cancel-in-progress: true` a secas: quédate con los conceptos y usa siempre los workflows de la
teoría.

| Vídeo | Por qué vale la pena | Comprobado |

| [GitHub Actions: Limit workflow runs & Control permissions for GITHUB_TOKEN](https://www.youtube.com/watch?v=JMHs5lYpvAM) — GitHub | El anuncio oficial de `concurrency`: grupos y cancelación contados por el equipo de producto. Complementa la teoría 06 | 2026-11-02 |
| [GitHub Actions: Concurrency](https://www.youtube.com/watch?v=PZ_A0QiLvz8) — Mickey Gousset | Una demo corta de un grupo con runs en curso, pendientes y cancelados. Mira cómo el pendiente se sustituye | 2026-11-02 |
| [Mastering GitHub Actions: Advanced Event Filtering (Branches, Paths & Types Explained)](https://www.youtube.com/watch?v=T56OFJLid8Y) — The DevOps Toolkit | `branches`, `paths` y `types` con ejemplos. Repasa las teorías 01 y 02 | 2026-11-02 |
| [Manually Trigger GitHub Actions Workflows Using workflow_dispatch](https://www.youtube.com/watch?v=nQRgTUwGBBA) — goobar | Un workflow con inputs lanzado desde la UI. Fíjate en si usa `inputs` o `github.event.inputs`, y por qué importa (teoría 04) | 2026-11-02 |
| [GitHub Actions: Trigger Workflow with actions/github-script](https://www.youtube.com/watch?v=ruXA4haAPoQ) — ePlus DEV | Lanzar un workflow desde otro con `github-script`, lo que hace `nightly.yml`. Comprueba que los datos entren por `env:` | 2026-11-02 |
