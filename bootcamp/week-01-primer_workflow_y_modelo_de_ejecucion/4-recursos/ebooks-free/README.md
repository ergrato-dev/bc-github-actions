# 📚 eBooks y material gratuito — Semana 01

Lecturas y cursos libres para profundizar en lo que la teoría resume. Ninguno es obligatorio.

| Recurso | Por qué vale la pena | Comprobado |
|---|---|:--:|
| [Hello GitHub Actions](https://github.com/skills/hello-github-actions) — GitHub Skills | Curso interactivo oficial: un bot revisa cada paso dentro de un repo tuyo. Repite en pequeño las prácticas 01 y 02; sus ejemplos fijan por tag, no por SHA, así que no los copies tal cual | 2026-11-02 |
| [Learn YAML in Y Minutes](https://learnxinyminutes.com/es/yaml/) — Learn X in Y Minutes | Toda la sintaxis de YAML en un archivo comentado y en español. Úsalo de chuleta junto a la teoría 02 | 2026-11-02 |
| [Learn to Use GitHub Actions: a Step-by-Step Guide](https://www.freecodecamp.org/news/learn-to-use-github-actions-step-by-step-guide/) — freeCodeCamp | Recorrido largo por los conceptos de la semana con otro ejemplo. Léelo como segunda explicación: usa `ubuntu-latest` y tags, justo lo que aquí no se hace | 2026-11-02 <!-- antipatron --> |
| [Pro Git](https://git-scm.com/book/es/v2) — Scott Chacon y Ben Straub | El libro de Git, gratuito y en español. Repasa ramas y remotos si el commit, push y pull request de la práctica 01 se te atascan | 2026-11-02 |
