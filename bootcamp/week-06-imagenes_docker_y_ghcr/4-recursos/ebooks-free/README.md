# 📚 eBooks y material gratuito — Semana 06

Lecturas libres para profundizar en lo que la teoría resume. Ninguna es obligatoria.

| Recurso | Por qué vale la pena | Comprobado |
|---|---|:--:|
| [Building images](https://docs.docker.com/get-started/docker-concepts/building-images/) — Docker | La serie oficial sobre capas, caché de build y multi-stage, con ejercicios cortos. Es la versión larga de las teorías 01 y 02 | 2026-11-02 |
| [Docker Build overview](https://docs.docker.com/build/concepts/overview/) — Docker | Cómo se reparten el trabajo el cliente buildx y el servidor BuildKit. Léelo antes de la teoría 03 si nunca habías oído hablar de drivers | 2026-11-02 |
| [Building best practices](https://docs.docker.com/build/building/best-practices/) — Docker | Orden de capas, `.dockerignore`, imágenes base fijadas y usuario no root, explicados uno a uno. Una lista contra la que revisar tus `Dockerfile` | 2026-11-02 |
| [OCI Image Format Specification](https://specs.opencontainers.org/image-spec/) — Open Container Initiative | La especificación de capa, manifiesto, índice y configuración en formato de libro. Para esta semana bastan los capítulos de manifiesto e índice | 2026-11-02 |
| [Container learning path](https://iximiuz.com/en/posts/container-learning-path/) — Ivan Velichko | Un itinerario libre de artículos con diagramas sobre qué es de verdad una imagen y cómo se construye. Buena segunda explicación de la teoría 01 | 2026-11-02 |
| [Publish to GitHub Packages](https://github.com/skills/publish-packages) — GitHub Skills | Un curso interactivo gratuito que publica una imagen en GHCR desde Actions dentro de tu propio repo. Usa versiones por tag: quédate con el flujo y aplica las reglas de la teoría | 2026-11-02 |
